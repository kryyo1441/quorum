# fixtures

`vectors.json` is generated by `generate.ts` (`pnpm fixtures`). Deterministic: fixed-seed PUBLIC TEST keys, fixed timestamps.
A test in `packages/log-core` regenerates it and fails if the committed file drifts.

Contents: 16 signed `ReleaseEntry`s, their leaf hashes, an STH over all 16 with 3 witness cosigs, inclusion proofs for every leaf,
consistency proofs 1/5/8/13/16 to 16, and `tampered.*` variants that every verifier must reject.

## What is signed (single source of truth: `packages/log-core/src/sign.ts`)
All JSON is canonical (sorted keys, no whitespace). Keys and signatures are base64 Ed25519.
- Leaf hash: `SHA256(0x00 || canonical(full ReleaseEntry incl. vendorSig))`. Node: `SHA256(0x01 || left || right)`.
- `vendorSig`: over `canonical(entry without vendorSig)`.
- `logSig`: over `canonical({logId, rootHash, timestamp, treeSize})`.
- Witness cosig: over `canonical({kind:"cosig", logId, rootHash, timestamp, treeSize, witnessId, cosigTimestamp})`.
  Binds the witness id and cosig timestamp; the `kind` tag stops a cosig being replayed as a log signature.
